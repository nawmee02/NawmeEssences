# GTM container — GTM-KKCJCDTZ

`gtm-kkcjcdtz-import.json` is generated by `node scripts/gtm/make-container.js`. It contains the GA4, Google Ads and Meta Pixel tags for the site's own `dataLayer` events, which come from `NawmeTrack` in `js/cart.js`. This folder is never published, because the deploy prunes `scripts/`.

## Import (once)
1. Open tagmanager.google.com → **GTM-KKCJCDTZ** → **Admin → Import Container**.
2. Choose `gtm-kkcjcdtz-import.json`, pick a **new workspace**, and select **Merge → Rename conflicting tags, triggers and variables**.
3. In **Tags**, look for anything that was already in the container, such as an old GA4 configuration tag. Pause or delete it so GA4 isn't sent twice.
4. Fill in the three constants in **Variables**:
   - `Meta Pixel ID`: Events Manager → your Pixel → ID (digits only)
   - `Google Ads Conversion ID`: Google Ads → Goals → Conversions → your **Purchase** action → Tag setup (digits only, without `AW-`)
   - `Google Ads Purchase Label`: the same screen, "Conversion label"
5. Click **Preview** and test on https://nawmeessences.com (see "Check before publishing"), then **Submit → Publish**.

## Settings outside GTM (required)
- **Meta Events Manager → Settings:** turn **off** "Automatic advanced matching". The cart form has a phone field, and the privacy notice promises we never send name, phone or address. Also turn off "Track events automatically without code".
- **GA4 → Admin → Data streams → Enhanced measurement:** keep page views, outbound clicks and file downloads. Turn **off**:
  - **Page changes based on browser history events** (the Quick Scent Match uses `pushState`, which would create fake page views);
  - **Scrolls**;
  - **Form interactions**;
  - **Site search** (the site sends its own `search` event).
- **Google Ads:** the Purchase conversion action should count **One** per order, with the value taken from the tag.

## What fires when
| Site event | GA4 | Google Ads | Meta |
|---|---|---|---|
| page load (when tags load) | page_view | remarketing | PageView |
| `view_item` (product page) | view_item | — | ViewContent |
| `add_to_cart` | add_to_cart | — | AddToCart |
| `begin_checkout` | begin_checkout | — | InitiateCheckout |
| `purchase`, **only after the order is saved in Supabase** | purchase | Purchase conversion | Purchase (eventID = order id) |
| `search` (shop `?q=`) | search | — | Search |
| `scent_match_*` (quiz) | same names | — | — |
| `order_save_failed` | diagnostics only | — | — |

Consent: visitors in Bangladesh are granted by default, which is admin-editable under **Site settings → Cookie consent**. Everyone else is denied until they click **Accept** on the banner.
- Google Ads and Meta tags require `ad_storage` + `ad_user_data`, so they do not fire for those visitors.
- GA4 sends only cookieless pings (Consent Mode v2).

Performance: the site loads GTM only after the first scroll, after a tap, or about 5 s after load. Meta's script is downloaded in a second idle step (`nawme_idle`). Keep the container lean: no click, scroll-depth, visibility or timer triggers, and no extra Custom HTML.

## Check before publishing
- **GTM Preview / Tag Assistant:** browse a product, add to cart, open the cart, then place a test order. `purchase` must appear only after the order shows in admin. Each tag should fire once.
- **GA4 → Admin → DebugView:** the same events appear with values in BDT.
- **Meta Events Manager → Test events:** PageView, ViewContent, AddToCart, InitiateCheckout and Purchase arrive, with no duplicates.
- **From outside Bangladesh** (or a VPN), the banner appears and nothing reaches Meta or Google Ads until you click Accept.
